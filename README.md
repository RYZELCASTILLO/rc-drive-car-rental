# RC Drive — Car Rental Services

A web-based car rental management system built for a Dumaguete City-based rental business. Customers can browse the fleet, book vehicles, request cancellations, and chat with support. Admins can approve bookings, manage cancellations, track pickups and returns, and monitor fleet availability in real time.

---

## Features

### Customer
- **Browse fleet** with live availability (shows remaining units per vehicle)
- **Book vehicles** by selecting pickup and return dates
- **View rental history** with status badges (Pending, Approved, Picked Up, Returned, Cancelled)
- **Request cancellation** with a reason (Change of date, No longer needed, Emergency, etc.)
- **Chat with support** through an in-dashboard conversation thread
- **Delete account** if no longer needed

### Admin
- **Approve or reject** pending bookings
- **Approve or reject** customer cancellation requests
- **Mark bookings** as Picked Up and Returned
- **Reply to client inquiries** through the conversation panel
- **Monitor fleet availability** by brand (total units, available, booked)
- **View live stats**: available cars, cars rented, total income, pending approvals
